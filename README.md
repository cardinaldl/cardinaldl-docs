# CardinalDL

A simple CLI and GUI for downloading videos.

Last updated for: v3.10.3

## Ways to run it

| Way | Best for | Docs |
| :-- | :-- | :-- |
| GUI | First time setup, signing into services, everyday use | - |
| CLI | Downloading and scripting from a terminal | [CLI setup](./CLI/README.md), [full reference](./CLI/CDL-CLI-DOCS.md) |
| Docker | Running headless on a server, *arr integration | [Docker guide](./docker/README.md) |

## Start here

If you are new, start with the desktop app. You sign in and log into your streaming services there, and you set your defaults. Both the CLI and the Docker server reuse that same setup, so the GUI is the place to get everything ready.
